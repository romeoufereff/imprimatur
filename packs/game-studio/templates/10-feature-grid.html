04 — Design pillars

What we won’t compromise on

Every run redraws the map

Twelve hand-authored bays are stitched procedurally, so layout is new every run but never incoherent.

Loss is legible, never cheap

A death always traces to a decision the player can name. No hit that came from off-screen.

Built for one, tuned for a crew

Drop-in co-op scales encounter density live — no separate balance pass, no lobby friction.

Progress survives every run

Meta-unlocks are permanent and visible from run one — a bad run still moves the account forward.
